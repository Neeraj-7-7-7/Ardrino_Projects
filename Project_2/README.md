# 🗣️ ESP32 Nova Wake Word Detector with Edge Impulse & BLE

Build a completely offline wake word detection system using ESP32, INMP441 microphone, and Edge Impulse. When the wake word "Nova" is detected with 95%+ confidence, the ESP32 triggers voice recognition on an Android phone via BLE.


---

## ✨ Features

- **100% Offline Processing** - No cloud, no internet, no API calls [citation:1][citation:8]
- **Custom Wake Word** - Trained on "Nova" using Edge Impulse (easily retrain for any word)
- **BLE Integration** - Triggers Android voice recognition when wake word is detected
- **High Accuracy** - 0.95 confidence threshold for reliable detection
- **Low Latency** - On-device inference in ~200-500ms [citation:1]
- **Privacy-Focused** - Audio never leaves the ESP32

## 🛠️ Hardware

| Component | Pins | Notes |
|-----------|------|-------|
| ESP32 30-pin CP2102 | - | Development board |
| INMP441 Microphone | See wiring below | MEMS I2S microphone |
| Android Phone | BLE | Receives BLE notifications |

### INMP441 → ESP32 Wiring

| INMP441 | ESP32 Pin |
|---------|-----------|
| VDD | 3.3V |
| GND | GND |
| SCK/BCLK | GPIO14 |
| WS/LRCL | GPIO15 |
| SD/DOUT | GPIO32 |
| L/R | GND |

## 📦 Dependencies

### Arduino Libraries
- `Audio_Classification_-_Keyword_Spotting_inferencing.h` (generated by Edge Impulse)
- `BLEDevice.h` (built-in ESP32 BLE)
- `driver/i2s.h` (built-in ESP32 I2S)

### Edge Impulse Deployment
1. Train model in Edge Impulse Studio
2. Deploy as Arduino Library (.zip)
3. Include in sketch folder
